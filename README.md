# CreaStudio オルソTIFF変換

オルソTIFFをブラウザ内で1枚に統合し、1 GB以内のLZW可逆圧縮GeoTIFFを作成するWebアプリです。

## 使い方

1. TIFFを選択、またはドラッグ＆ドロップします。入力の合計は6 GBまでです。
2. 「TIFFを作成」を押します。
3. 「TIFFをダウンロード」で保存します。ファイル名は「6-1 オルソ 出来形計測データ.tiff」です。

「TIFFビューア」では拡大・縮小・移動・全体表示ができます。TIFFを1枚ドロップして開くこともできます。読み込み中はプログレスバーを表示します。

CreaStudioロゴをクリックすると、[CreaStudio会員ページ](https://member.creastudio.co.jp/index.php)を新しいタブで開きます。

## データと圧縮

- 入力は合計6,000,000,000バイトまで、出力は1,000,000,000バイト以内です。
- 8ビットのRGB・RGBA・グレースケール・パレットTIFFに対応します。
- 複数枚は、座標系・解像度・画素位置がそろった北向きのGeoTIFFを使用します。
- 出力の圧縮はLZWです。圧縮は可逆です。
- 1 GBを超える場合は、座標範囲を保って最近傍法で解像度を下げます。画素の間引きで失われた情報は復元できません。
- 重なりでは、後に追加した画像の透明でない画素を優先します。
- 画像はブラウザ内で処理します。変換中はページを開いたままにしてください。

## 設置

ビルド済みの `docs/` の中身を、HTTPSで配信できる公開フォルダーに配置してください。サブフォルダーにも設置できます。

GitHub Pagesでは `main` ブランチの `/docs` を公開元に指定できます。

CSSとJavaScriptのファイル名には、内容から算出した識別子が付きます。更新時は `index.html` と関連ファイルを一式配置してください。

## 開発

Node.js 20以降を使用します。

```sh
npm ci
npm run build
npm start
```

起動後、表示されたローカルURLをChromeまたはEdgeで開きます。

| フォルダー | 内容 |
| --- | --- |
| `web/` | HTML・CSS・画面操作と画像素材 |
| `src/` | TIFF統合、LZW圧縮、画像読み込み |
| `scripts/` | ビルドとローカル確認 |
| `docs/` | 配信するビルド済みファイル |

第三者ライブラリのライセンス表示は `docs/third-party-notices.txt` にまとめています。ローディングCSSには提供元の表記を残しています。
